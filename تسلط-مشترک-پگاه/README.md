# تسلط-مشترک-پگاه

اسکیل تسلط بر اسکیمای `Global` دیتابیس `PegahAI` — **واژگانِ مشترکِ کلِ
دیتابیس**. در فرمت استاندارد `SKILL.md`. مستقل است: این پوشه را هرجا بگذاری
کار می‌کند.

```
SKILL.md                      دستورالعمل — چیزی که مدل هر بار می‌خواند
schema.json                   نقشه‌ی ماشین‌خوان ۱۱۹ جدول (داده، نه کد)
scripts/map.py                پیمایش نقشه — table / refs / path / find / domain / external / crossref / traps / drift
references/entities.md        دامنه به دامنه
references/relationships.md   گراف اتصال و تله‌ها
references/queries.md         کوئری‌های تأیید و الگوهای دامنه
references/reporting.md       شکل گزارش و داده‌ی هویتی
examples/walkthrough.md       یک سؤال واقعی از اول تا آخر
```

## چرا این اسکیل با بقیه فرق دارد

بقیه‌ی اسکیل‌ها یک دامنه‌ی کسب‌وکاری را پوشش می‌دهند. این یکی **واژگانی است
که همه‌شان به کار می‌برند**: افراد، ساختار سازمانی، تقویم، گروه‌بندی، بانک،
آدرس.

جریان تقریباً یک‌طرفه است — **۱۰ ارجاع بیرونی** از اینجا به بقیه، در برابر
صدها ارجاع از بقیه به اینجا:

## پنج تله که وقت زیادی می‌گیرند اگر از قبل ندانی

- **`Markaz` و `MarkazPakhsh` دو چیزِ متفاوت‌اند** و هر دو پرارجاع.
  `HumanResource` بیشتر اولی را می‌گوید و `Sales` دومی را. قاطی کردنشان یعنی
  گزارشی که در یک اسکیما درست و در دیگری غلط است. و
  `Markaz.ccMarkazPakhsh_Old` **ستونِ مرده** است.
- **`Goroh` چندریخت است.** `ccGorohLink` تفکیک‌کننده: **۵۶۰** گروه کالا،
  **۳۰۴** نوع مشتری. بدون فیلتر، این دو در یک جدول قاطی‌اند و چون هر دو
  `NameGoroh` دارند **خطا دیده نمی‌شود**.
- **`Taghvim.TarikhShamsi` از نوع `int` است** (`14050531`)، نه رشته.
- **سه سلسله‌مراتبِ سازمانی** که همه به فارسی «منطقه» دارند: پخش، فروش، و
  `Markaz`. جمع زدن روی یکی و برچسب زدن با دیگری معمول‌ترین خطای گزارش‌های
  مدیریتی است.
- **پنج نامِ متفاوت برای «فعال»**: `Faal`، `CheckFaal`، `GhabeleEstefade`،
  `IsActive`، `Faal2`. در جدولِ مرجع رکوردِ غیرفعال می‌ماند.

`python scripts/map.py traps` تله‌های ساختاری را یک‌جا می‌دهد.

## اجرای مستقیم

```bash
python scripts/map.py table  Afrad
python scripts/map.py refs   MarkazPakhsh
python scripts/map.py path   MarkazPakhsh Houzeh
python scripts/map.py find   Taghvim
python scripts/map.py domain sazman
python scripts/map.py external
python scripts/map.py crossref ccMarkazForosh
python scripts/map.py traps
python scripts/map.py drift  live-tables.txt
```

پایتون ۳.۹ به بالا، بدون وابستگی بیرونی.

**هر پنج اسکیلِ دیگر به این یکی تکیه دارند.** `Global.Afrad` پلی است که

منطقِ تاریخی در کلِ دیتابیس است.

## نقشه از کجا آمده و چقدر قابل اعتماد است

- **جدول‌ها و ستون‌ها:** از فهرست کاملِ اشیای `PegahAI`. دقیق است.
- **۱۱۸ یالِ داخلی:** از قاعده‌ی `A.ccB → B`. **هیچ‌کدام کلید خارجیِ
  اثبات‌شده نیست.**
- **عددهای ارجاعِ ورودی:** با شمارشِ مستقیم روی فهرست کاملِ دیتابیس. دقیق‌اند.
- **۲۴ نقشِ جدول:** از بررسی ساختار ستون‌ها، به‌علاوه‌ی دانشِ دو اسکیلِ
  **تست‌شده**ی فروش (`ccGorohLink = 560/304`، لاین‌های فروش، تقویم).
- **کوئری‌ها:** الگو هستند و **اجرا نشده‌اند**.

نقشه از یک نسخه‌ی پشتیبان است. `map.py drift` تطبیق با دیتابیس زنده می‌دهد.

## پیوند با بقیه‌ی اسکیل‌ها

این اسکیما **واژگان** است: ۱۰۲ ارجاع از چهار اسکیمای دیگر به آن، و فقط ۷
ارجاع از آن به بیرون. هر تعریفی که اینجا عوض شود در چهار اسکیل دیگر هم باید
عوض شود.

| اسکیما | چند جدولِ اینجا را می‌خواند | اسکیل |
|---|---:|---|
| `Sales` | ۳۸ | `تسلط-فروش-پگاه` |
| `HumanResource` | ۲۳ | `منابع-انسانی-پگاه` |
| `Treasury` | ۲۲ | `تسلط-خزانه-پگاه` |
| `Warehouse` | ۱۹ | `تسلط-انبار-پگاه` |

دو حفره‌ی خانوادگی که ریشه‌شان اینجاست و **در هیچ اسکیمای نقشه‌شده‌ای جدول
ندارند**: جغرافیا (`ccShahr` ۲۶، `ccMantagheh` ۱۴، `ccMahaleh` ۱۳،
`ccOstan` ۱۰، `ccShahrestan` ۸) و هویت کاربر (`ccUser` ۱۳۶،
`ccUserSabtKonandeh` ۷۲، `ccUserSabegheh` ۵۳ — روی هم ۲۶۱ ارجاع).

نقشه‌ی کامل خانواده، ماتریسِ ارجاع و فهرستِ ارجاع‌های حل‌نشده در
[../SKILLS.md](../SKILLS.md). عددها را `crosslink.py` می‌سازد؛ دستی
به‌روزشان نکن.

۱. **مقادیر `ccGorohLink` را کشف کن** (کوئری ۰.۱). فقط ۵۶۰ و ۳۰۴ شناخته
   شده‌اند؛ بقیه معلوم نیست چه‌اند.
۲. **رابطه‌ی `Markaz` و `MarkazPakhsh`** — کوئری ۰.۲ ساختار را نشان می‌دهد،
   ولی معنیِ کسب‌وکاری‌اش را باید پرسید.
۳. **آزمونِ یتیم از بیرون** روی `ccAfrad`، `ccMarkaz`، `ccMarkazPakhsh` —
   این پل‌ها زیرِ پای پنج اسکیل‌اند.
۴. **`ccShahr` حل‌نشده است** (۶۵ ارجاع در کلِ دیتابیس). `Address.ccShahr`
   وجود دارد ولی جدولِ `Shahr` در هیچ اسکیمایی پیدا نشد.
۵. **`TaghvimTatil` در برابر `TaghvimTatilManabeEnsani`** — کدام مبنای روز
