# تسلط-خزانه-پگاه

اسکیل تسلط بر اسکیمای `Treasury` دیتابیس `PegahAI`، در فرمت استاندارد
`SKILL.md`. مستقل است: این پوشه را هرجا بگذاری کار می‌کند.

```
SKILL.md                      دستورالعمل — چیزی که مدل هر بار می‌خواند
schema.json                   نقشه‌ی ماشین‌خوان ۱۵۲ جدول (داده، نه کد)
scripts/map.py                پیمایش نقشه — table / refs / path / find / domain / external / traps / drift
references/entities.md        دامنه به دامنه
references/relationships.md   گراف اتصال، پل‌های بین‌اسکیمایی، تله‌ها
references/queries.md         کوئری‌های تأیید و الگوهای دامنه
references/reporting.md       شکل گزارش و انضباطِ پول
examples/walkthrough.md       یک سؤال واقعی از اول تا آخر
```

|---|---:|

۵۴ ویو از نقشه بیرون است.

## شش تله که وقت زیادی می‌گیرند اگر از قبل ندانی

- **جهانِ موازیِ `PPC`.** پنج جفت جدول با ساختارِ تقریباً یکسان و **همان نام
  کلید**: `DariaftPardakht`/`DariaftPardakhtPPC` (۵۴ در برابر ۶۳ ستون) و
  چهار جفتِ دیگر. `PPC` یعنی ثبت روی دستگاه همراه. **جمعِ هر دو یعنی
  دوباره‌شماریِ پول.**
- **مبلغ فقط در سربرگ نیست.** `DariaftPardakhtVazeiat` ستون `Mablagh` دارد —
  مبلغ با تغییرِ وضعیت عوض می‌شود.
- **`BedBes` جهت است، نه مقدار.** جمعِ بدونِ علامت، بدهکار و بستانکار را با
  هم جمع می‌کند.
- **`ccHesab0` تا `ccHesab7`** در `EjazehPardakhtFaktorSatr` — هشت سطحِ
  کدینگ حساب. گزارش در سطحِ اشتباه بی‌معنی است.
- **`ccRefrence` چندریخت** در `SandoghMarkazi`، و `ccLinkSandoghMarkazi`
  خودارجاع.
- **`EjazehPardakhtPishPardakht.ccTankhahDar` از نوع `nchar`** است ولی
  مقصدش `bigint` — join بدون `CAST` بی‌صدا نمی‌خورد.

`python scripts/map.py traps` تله‌های ساختاری را یک‌جا می‌دهد.

## جای این اسکیل در مجموعه

| سؤال | اسکیل |
|---|---|
| خزانه، دریافت/پرداخت، تنخواه، چک | **این** |
| فروش، فاکتور، هدف، تخفیف | `تسلط-فروش-پگاه` |
| انبار، موجودی، کالا | `تسلط-انبار-پگاه` |
| پرسنل و حقوق | `منابع-انسانی-پگاه` |
| نمره‌ی فروشنده | `ارزیابی-فروشنده-پگاه` (**تست‌شده**) |
| درجه‌بندی مشتری | `رتبه-بندی-مشتریان-پگاه` (**تست‌شده**) |

**این اسکیما جایی است که تعهدِ همه‌ی دامنه‌ها به پولِ واقعی تبدیل می‌شود.**
`EjazehPardakhtFaktor` مقصدِ ارجاع از `HumanResource` (حقوق، وام،
تسویه‌حساب، هزینه درمان)، `Sales` و `AssetAccounting` است.

## نقشه از کجا آمده و چقدر قابل اعتماد است

- **جدول‌ها و ستون‌ها:** از فهرست کاملِ اشیای `PegahAI`. دقیق است.
- **۱۱۰ یال:** از قاعده‌ی `A.ccB → B`. **هیچ‌کدام کلید خارجیِ اثبات‌شده
  نیست.**
- **۴۳ پل بین‌اسکیمایی:** مقصدشان در فهرست اشیای دیتابیس پیدا شده.
- **۲۲ نقشِ جدول:** از بررسی ساختار ستون‌ها نوشته شده.
- **کوئری‌ها:** الگو هستند و **اجرا نشده‌اند**.

نقشه از یک نسخه‌ی پشتیبان است. `map.py drift` تطبیق با دیتابیس زنده می‌دهد و
وقتی چیزی عوض نشده ساکت می‌ماند.

## کارهای باقی‌مانده — به ترتیب اهمیت

۱. **جهانِ PPC را حل کن** (کوئری ۰.۲). تا این روشن نشده، **هیچ جمعِ ریالی
   قطعی نیست**. این تنها موردی است که کلِ اسکیل را معلق نگه می‌دارد.
۲. **جهتِ `BedBes`** (کوئری ۰.۴). علامتِ وارونه یعنی گزارشِ دقیقاً برعکس.
۳. **مبلغِ سربرگ در برابر وضعیت** (کوئری ۰.۶).
۴. **کلید خارجی و تعداد سطر** — و آزمونِ یتیم روی
   `ccEjazehPardakhtFaktor`، `ccDariaftPardakht`، `ccSandogh`.
۵. **کدهای وضعیت** هر دامنه — کدام معتبر، کدام باطل.

## آنچه باید با خزانه‌دار چک شود

- **PPC** سینک است یا مجموعه‌ی جدا.
- **`BedBes = 1`** بدهکار است یا بستانکار.
- **وصولِ واقعی** مبلغِ سند است یا مبلغِ آخرین وضعیت.
- **چکِ وصول‌نشده** در «وصول» حساب می‌شود یا نه.
- **مانده‌ی اول سال** در گزارشِ دوره‌ای بیاید یا نه.
- **`Kardex.ccRefrence`‌مانندِ `SandoghMarkazi.ccRefrence`** به چه اشاره
  می‌کند.
