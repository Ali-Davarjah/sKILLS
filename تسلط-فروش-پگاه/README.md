# تسلط-فروش-پگاه

اسکیل تسلط بر اسکیمای `Sales` دیتابیس `PegahAI`، در فرمت استاندارد
`SKILL.md`. مستقل است: این پوشه را هرجا بگذاری کار می‌کند.

```
SKILL.md                      دستورالعمل — چیزی که مدل هر بار می‌خواند
schema.json                   نقشه‌ی ماشین‌خوان ۴۳۵ جدول (داده، نه کد)
scripts/map.py                پیمایش نقشه — table / refs / path / find / domain / external / traps / drift
references/entities.md        دامنه به دامنه: جدول، کلید، نشانه‌ها
references/relationships.md   گراف اتصال، پل‌های بین‌اسکیمایی، تله‌ها
references/queries.md         کوئری‌های تأیید و الگوهای دامنه
references/reporting.md       شکل گزارش
examples/walkthrough.md       یک سؤال واقعی از اول تا آخر
```

## این اسکیل کجای مجموعه می‌نشیند

سه اسکیل روی اسکیمای `Sales` هست و کارشان یکی نیست:

| اسکیل | کار | وضعیت |
|---|---|---|
| **تسلط-فروش-پگاه** (این) | نقشه: کدام جدول، کدام مسیر، کدام تله | نقشه تأییدشده، کوئری‌ها اجرانشده |
| `ارزیابی-فروشنده-پگاه` | نمره و رتبه‌ی فروشنده | **تست‌شده روی داده‌ی واقعی** |
| `رتبه-بندی-مشتریان-پگاه` | درجه‌بندی مشتری | **تست‌شده روی داده‌ی واقعی** |

اگر سؤال دقیقاً یکی از آن دو کار است، **از همان اسکیل استفاده کن** — عددهایش
سنجیده شده. این اسکیل برای بقیه‌ی سؤال‌های فروش است و برای فهمیدنِ زمینه.

۱۳۵ ویو از نقشه بیرون است. عددِ ۴۳۵ فریبنده است: یک‌پنجمش جدولِ موقتِ گزارش
است.

## هفت تله که وقت زیادی می‌گیرند اگر از قبل ندانی

- **سه جدولِ خوش‌نام مرده‌اند.** `AmalkardRozanehForosh` (۲۰۱۸)،
  `HadafForosh` (۲۰۱۸)، و `HadafForoshRoozaneh` بدونِ `New` که ستون هدفش در
  ۱۴۰۵ صفر است. هدف را از `HadafForoshRoozanehNew` بگیر.
- **`AmarForosh_Arshive` آرشیو نیست، جدولِ اصلیِ فروش است.** اسمش گمراه
  می‌کند.
- **`ccForoshandeh` مسیر است نه آدم.** برای شخص از `ccAfradForoshandeh` به
  `Global.Afrad`. و `SharhForoshandeh` کد است نه نام.
- **مرجوعی دو منبع دارد.** `IsMarjoee = 1` علت ندارد و شماره فاکتور ندارد؛
  `ElamMarjoee` علت دارد ولی ۱۰ تا ۲۵ برابر کمتر است.
- **بدون `ccNoeForoshandeh = 1`**، سرپرست و رییس مرکز که عددشان تجمیع تیم
  است صدر جدول را می‌گیرند.
- **`Global.vGorohMahsol` فقط ۳۳ گروه از ۵۵ را دارد** — نام گروه را از
  `Global.Goroh` با `ccGorohLink = 560` بگیر.
- **۸۲ جدولِ `Tmp_`/`rpt_`** که شبیه جدولِ واقعی‌اند. `map.py domain
  gozaresh` همه را می‌دهد.

`python scripts/map.py traps` تله‌های ساختاری را یک‌جا می‌دهد.

## اجرای مستقیم

```bash
python scripts/map.py table  AmarForosh_Arshive
python scripts/map.py refs   Moshtary
python scripts/map.py path   Moshtary AmarForosh_Arshive
python scripts/map.py find   Jayezeh
python scripts/map.py domain gozaresh
python scripts/map.py external
python scripts/map.py traps
python scripts/map.py drift  live-tables.txt
```

پایتون ۳.۹ به بالا، بدون وابستگی بیرونی.

## نقشه از کجا آمده و چقدر قابل اعتماد است

- **فهرست جدول‌ها و ستون‌ها:** از فهرست کاملِ اشیای `PegahAI` (۳۰۸۴۹ ستون،
  ۱۸ اسکیما). دقیق است.
- **۹۲۸ یال اتصال:** از قاعده‌ی `A.ccB → B` حدس زده شده. **هیچ‌کدام کلید
  خارجیِ اثبات‌شده نیست** — این اسکیما کلید خارجی اعلام‌شده ندارد.
- **۶۱ پل بین‌اسکیمایی:** مقصدشان در فهرست اشیای دیتابیس پیدا شده، پس
  مقصد قطعی است.
- **نقشِ ۱۶ جدولِ کلیدی و تله‌های دامنه‌ای:** از دو اسکیلِ **تست‌شده**ی فروش
  آمده — این‌ها روی داده‌ی واقعی سنجیده شده‌اند.
- **کوئری‌ها:** الگو هستند و **اجرا نشده‌اند**.

نقشه از یک نسخه‌ی پشتیبان است. `map.py drift` تطبیق با دیتابیس زنده را
می‌دهد و وقتی چیزی عوض نشده ساکت می‌ماند.

## کارهای باقی‌مانده

۱. **کلید خارجی و تعداد سطر را بگیر** (بخش ۰.۱ و ۰.۴ `queries.md`). با
   تعداد سطر می‌شود گفت کدام جدولِ `Tmp_` واقعاً استفاده می‌شود.
۲. **آزمونِ یتیم** روی `ccMoshtary`، `ccForoshandeh`، `ccKalaCode`،
   `ccDarkhastFaktor` — تا یال‌ها از حدس به اثبات بروند.
۳. **کوئری‌ها را اجرا کن** و بالای هرکدام «تست‌شده» بنویس.
۴. **جدول اندازه‌ها** در انتهای `queries.md` را با عددهای واقعی پر کن.
۵. **نقشِ جدول‌های دامنه‌ی تخفیف/جایزه** (۶۱ جدول) هنوز نوشته نشده —
   بزرگ‌ترین بخشِ ناشناخته‌ی این اسکیما.

## آنچه باید با مدیر فروش چک شود

- **واحد هدف** — تعدادی پیش‌فرض است؛ ریالی و وزنی جواب متفاوت می‌دهند.
- **مرجوعیِ اعلام‌شده یا ثبت‌شده** و اینکه مسئولیت ۴ (فروش و پخش) شمرده شود
  یا نه.
- **مقایسه‌ی بین‌لاینی** با مبنای یکسان درست است یا نه.
- **دامنه‌ی تخفیف و جایزه** — ۶۱ جدول با نام‌های نزدیک؛ کدام‌ها زنده‌اند.
